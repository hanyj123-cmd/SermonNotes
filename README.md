# 말씀결 (sermon-notes) — v9

교회 유튜브 설교 영상의 자막을 Gemini AI가 **4가지 방식**으로 정리해 주는 웹앱입니다. 개혁주의(대한예수교장로회 합동·통합) 신학 기준으로 쓰도록 프롬프트가 설계되어 있습니다 (`scripts/lib/prompt.mjs`).

| 모드 | 내용 |
|---|---|
| **설교리뷰** | 설교 정리(대지별) + Summary |
| **QT 묵상** | 여는 기도 · 찬송가 1곡+CCM 1곡 · 4역본 성경 · 잔잔한 묵상 음악 1곡(설교마다 다르게) · QT 정리 · 묵상 질문 · 삶의 적용(로그인하면 내 글 저장) · 맺는 기도 |
| **성경공부** | 여는 기도 · 찬양 · 성경 · 신학 딥다이브(원어·주석) · Summary · 퀴즈 15문제(객관식 5·빈칸 5·주관식 5, 답은 [답보기]로) · 맺는 기도 |
| **소그룹 나눔** | 대표 기도 · 찬양 · 정리 · 적용 · 질문(로그인 메모 / 핸드아웃 줄 / [모범 답안 보기]) · 삶 나눔·기도제목 나눔 가이드 · 맺는 기도 |

모든 설교 화면 위쪽에는 **한 줄 정리 · 영상 보기 · 핸드아웃 PDF 버튼 · 4가지 모드 탭**이 있습니다.

## 화면 구성

- **말씀 게임** (첫 화면): 캐릭터 · 도장 · 달란트 · 여정. 홈 맨 위에 **오늘의 말씀 읽기** 카드가 있고, 탭에 **일독표**가 있습니다.
- **오늘의 말씀**: 토론토영락교회 앱의 날짜별 성경 읽기 분량. 본문(개역개정 · NIV · 표준새번역) / QT 묵상 / 성경공부 / 소그룹 나눔 / 퀴즈. 장마다 공동체 성경읽기 영상, 카톡 메시지 복사 · 보내기.
- **토론토영락교회 설교**: 주일예배 탭 + 지난 설교 탭(이미 정리된 새벽기도 · 수요예배 · 청년부).
- **사용자 영상**: 유튜브 링크를 넣고 날짜·제목·성경 본문·설교자를 직접 입력하면(비워도 됨) 같은 형식으로 정리됩니다.
- **관리** (오른쪽 위): 재생목록 · 영상 선택 정리 · AI 모델 · 지금 동기화.

## 오늘의 말씀 읽기

- 본문은 화면이 교회 성경 서버(`ynchurch.com/ync/web/getBibleVerses/`)에서 날짜별로 바로 가져옵니다. 전날 · 다음날로 넘겨 볼 수 있습니다.
- 매일 아침 7시(토론토) 동기화가 **다음 날** 분량(혹시 빠졌으면 오늘 것도)의 QT 묵상 · 성경공부 · 소그룹 나눔 · 퀴즈(객관식 15 · 빈칸 5 · 주관식 5, 쉬움·중간·어려움 섞어서, 본문에서만) · 장별 한두 줄 요약 · 공동체 성경읽기 유튜브 영상을 찾아 시트 `Daily` 탭에 저장합니다.
- 공동체 성경읽기 영상은 **공동체성경읽기 채널(@PRS)**의 장별 영상("열왕기상 11장")을 1순위로, 없는 장만 CGN "하루 20분 공동체성경읽기" 재생목록으로 채웁니다. `docs/data/reading-videos.json` 에 성경 1,189장 전부의 @PRS 영상이 이미 들어 있고, 한 달에 한 번 채널 영상 목록을 다시 훑어 장별 색인(`docs/data/reading-videos.json`)을 만들고, 그날 장에 맞는 영상을 바로 연결합니다(색인에 없을 때만 유튜브 검색). 화면도 이 색인으로 빠진 날을 채웁니다. 화면에서 누르면 떠 있는 재생 창에서 열리고, 다른 화면으로 옮겨 가도 계속 들립니다. **전체 이어 듣기**를 누르면 그날 영상을 차례로 이어서 틉니다. 카톡 메시지에도 이 영상 링크가 들어갑니다. 영상을 못 찾은 장만 "찾기"(유튜브 검색) 버튼으로 보입니다.
- **성경공부(오늘의 말씀)**: 책과 본문의 배경, 장마다 구간별 **절별 주석**(관련 구절 · 주석가들의 해석 요지), 신학적 깊이 보기, Summary까지 주석서 수준으로 자세히 만듭니다. 절별 주석은 시트 `Daily` 탭의 `commentary_json` 열에 따로 저장됩니다.
- **관리 → 날짜별 진행 상황 → 다시 만들기**: 날짜마다 전부 또는 성경공부 · QT · 소그룹 · 퀴즈 · 영상 중 하나만 골라 다시 만들 수 있습니다(Actions 입력 `daily_modes`).
- 화면 맨 아래에 자료 업데이트 시각과 **앱 업데이트(푸시) 시각 · 버전**이 보입니다.
- **관리 → 오늘의 말씀 동기화**: 과거 5일 ~ 미래 2일(8일치) 중 빠진 날을 지금 만듭니다. 아래 "날짜별 진행 상황"에서 완료 · 만드는 중 · 실패 · 중단됨과 QT/공부/소그룹/퀴즈/영상 여부를 볼 수 있습니다(실행 중에는 10초마다 새로 봄). "이미 만든 날도 다시 만들기"를 체크하면 전부 새로 만듭니다.
- 본문 끝까지 읽고 **다 읽었어요**를 누르면 경험치 · 달란트 · 오늘의 도장을 받고, 그날 장들이 **일독표**에 자동 체크됩니다. 다른 곳에서 읽은 장은 일독표에서 칸을 눌러 직접 체크하거나 해제합니다.
- 말씀 게임의 **성경말씀 퀘스트**: 주일 설교가 올라온 주에는 주일 설교 퀴즈부터, 그다음 오늘의 말씀 퀴즈, 지난 며칠 말씀 순서입니다(새벽기도는 빠짐).
- **PDF**: 오늘의 말씀 화면의 "PDF 미리보기 · 다운로드" — 말씀 읽기(요약 + 본문 + 묵상 노트) / QT 묵상 / 성경공부 · 퀴즈 / 소그룹 나눔, 용지 · 역본 · 쓰는 줄 · 정답 포함 옵션은 설교 PDF와 같습니다.
- 묵상 · 공부 · 소그룹 앞 찬양은 CCM 한 곡만 추천합니다(유튜브 검색 링크).
- 지난 날짜를 한꺼번에 만들려면 Actions 직접 실행에서 `daily_dates` 에 `2026-10-01,2026-10-02` 처럼 넣습니다(최대 14일).

## 새벽기도 영상 연결

- 오늘의 말씀 화면의 **새벽기도 보기** 버튼(공동체 성경읽기 버튼 옆, 게임 홈 카드에도)을 누르면 그 날 새벽기도 영상이 앱 안 떠 있는 창에서 재생됩니다. AI 정리 없이 영상만 날짜에 1:1로 연결합니다(시트 `Daily` 탭의 `dawn_json` 열).
- 자동: 매일 **07:20** 재생목록에서 그 날 올라온 영상을 찾아 연결하고, 오늘 영상이 아직 없으면 **08:00**에 한 번 더 찾습니다(이미 있으면 재생목록을 다시 읽지 않음). 다른 동기화 때도 최근 7일 중 빈 날을 채웁니다. 영상 제목의 날짜(예: `[2026.10.09]`)가 있으면 그 날짜, 없으면 올라온 날짜(토론토)로 맞춥니다. 예정된 라이브·방송 중인 영상은 건너뜁니다.
- **관리 → 새벽기도 영상**: 재생목록 주소 바꾸기(Settings 탭 `dawn_playlist`, 기본값 `PLexqr1dnrjPzF_IXx_pR1YRKUx13rX7CT`), **수동 업데이트 실행**, 날짜별로 영상 주소 **직접 연결/해제**. 직접 연결한 날짜는 자동 실행이 바꾸지 않습니다.
- 연결된 영상이 없을 때는 이미 정리된 새벽기도 설교(같은 날짜)를 대신 보여 줍니다. 카톡 메시지에도 새벽기도 링크가 들어갑니다.
- Actions 직접 실행에서 `categories` 에 `dawn_video` 를 넣으면 새벽기도 영상 연결만 짧게 실행합니다.

## 자동 수집 시각 (토론토 시간)

| 구분 | 자동 수집 |
|---|---|
| 오늘의 말씀 (다음 날 분량) | 매일 오전 7:00 |
| 새벽기도 영상 연결 | 매일 오전 7:20, 못 찾으면 8:00 다시 |
| 주일예배 | 매주 일요일 밤 10:00 |
| 새벽기도 · 수요예배 · 청년부 | 자동 없음 (이미 정리된 것은 "지난 설교"에 남아 있음) |

GitHub 예약은 UTC만 되고 토론토는 서머타임이 있어서, `sync.yml` 에 여름·겨울용 예약을 둘 다 등록하고 `scripts/gate.mjs` 가 맞는 쪽만 실행합니다. 직접 실행은 시각과 상관없이 항상 실행됩니다. 사용자 영상과 "다시 정리"로 표시한 영상은 어떤 실행에서든 먼저 처리됩니다.

영상 제목이 `[YYYY.MM.DD] 설교제목 (성경본문) - 설교자` 형식이면 날짜 · 제목 · 본문 · 설교자가 자동으로 태그됩니다.

## 설정 순서 (처음 한 번)

1. **Google Sheet** 만들기 — 첫 탭 이름 `Playlists`, 1행 `category · playlist_url · max_videos`. `category` 는 `주일예배 / 새벽기도 / 수요예배 / 청년부예배` (또는 `sunday / dawn / wednesday / youth`). 나머지 탭(Sermons · Notes · Settings)은 자동으로 만들어집니다. 주소창의 `/d/`**`여기`**`/edit` 가 `SHEET_ID`.
2. **Google Cloud**: Google Sheets API + YouTube Data API v3 사용 설정 → API 키(= `YOUTUBE_API_KEY`) → 서비스 계정 만들고 JSON 키 내려받기(= `GOOGLE_SERVICE_ACCOUNT_JSON`) → 서비스 계정 이메일을 시트 **편집자**로 공유.
3. **GitHub**: 새 저장소에 이 폴더를 올리고(`.env` 제외), Settings → Secrets and variables → Actions 에 `SHEET_ID`, `GOOGLE_SERVICE_ACCOUNT_JSON`, `YOUTUBE_API_KEY`, `GEMINI_API_KEY` (선택: `SUPADATA_API_KEY`) 등록. 선택 Variables: `GEMINI_MODEL`, `MAX_NEW_PER_RUN`(5), `RETRY_DAYS`(7), `AUTO_WITHIN_DAYS`(14), `GEMINI_VIDEO`(off 로 두면 영상 직접 분석 끔).
4. **Pages**: Settings → Pages → Deploy from a branch → `main` / `/docs`.
5. **Apps Script**: 시트의 확장 프로그램 → Apps Script 에 `apps-script/Code.gs` 를 붙여넣고, 스크립트 속성에 `ADMIN_PASSWORD`, `GOOGLE_CLIENT_ID`, `ALLOWED_EMAILS`(가족 구글 계정, 쉼표로), `GITHUB_TOKEN`·`GITHUB_REPO`(앱에서 "지금 동기화"를 쓰려면) 입력 → 배포 → 웹 앱 주소를 `docs/config.js` 의 `ADMIN_API_URL` 에.
   - **이미 배포한 적이 있다면**: 코드를 바꿔 붙인 뒤 **배포 관리 → 편집 → 새 버전**으로 다시 배포하세요(주소는 그대로). `Notes` 탭에 `fields_json` 칸은 자동으로 추가됩니다.
6. **Actions → 설교 자막 정리 동기화 → Run workflow** 로 첫 실행. 처음엔 `max_new` 를 1~2 로 두고 결과를 확인하세요.

### Actions 직접 실행 옵션

| 입력 | 뜻 |
|---|---|
| `max_new` | 이번에 정리할 최대 영상 수 |
| `categories` | `sunday,dawn,wednesday,youth` 중 쉼표로. 비우면 청년부 제외, `all` 전부, `user` 는 사용자 영상·다시 정리 표시한 것만 |
| `export_only` | `true` 면 새로 정리하지 않고 시트 내용을 사이트에 반영만 함 (제목·설교자를 고친 뒤 앱이 자동으로 씀) |
| `daily_dates` | 오늘의 말씀을 만들 날짜들 (쉼표로, 최대 14일). 비우면 내일 · 오늘 중 빠진 것 |
| `daily_force` | `true` 면 이미 만든 날도 다시 만듦 |
| `bible_check` | `true` 면 성경 본문 가져오기 점검만 실행 (4역본이 지금도 읽히는지) |

## 성경 본문 (웹사이트에서 읽기)

- 개역개정 · 표준새번역: 대한성서공회(bskorea.or.kr), NIV · 메시지 성경: BibleGateway. 영상 제목의 본문(예: `열왕기상 4, 5장`)을 읽어 설교마다 붙입니다.
- 화면에는 역본 **버튼 4개**로 하나씩 보여 주고, 핸드아웃은 기본 개역개정 · 역본 선택 또는 4개 모두 선택할 수 있습니다.
- 사이트 화면 구조가 바뀌면 읽지 못할 수 있습니다. 확인: Actions 의 `bible_check`, 또는 내 컴퓨터에서 `node scripts/bible-check.mjs "요한복음 3:16-18"`. 일부 역본이 안 읽혀도 나머지로 정리는 완료됩니다.

**개역개정 낭독 듣기**: 개역개정 탭 아래에 "듣기"가 나옵니다. 동기화 때 유튜브에서 `드라마바이블 창세기 12장` 같은 검색으로 이미 올라와 있는 음원을 찾아(제목에 책 이름과 장 번호가 맞는 영상만) 앱 안에서 재생합니다. 장 단위이고, 못 찾으면 유튜브 검색 링크로 열립니다. 음원을 직접 저장하거나 올리지 않습니다.

## 유튜브 재생 (떠 있는 재생 창)

- 설교 영상 · 찬양 · 묵상음악 · 성경 낭독은 모두 **앱 안의 떠 있는 재생 창**에서 재생됩니다 (새 창으로 열지 않음).
- 제목줄을 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꿉니다. 다른 화면으로 가도 계속 재생됩니다.
- 조절 막대: 진행 막대(끌어서 이동) · **15초 뒤로 / 재생·일시정지 / 15초 앞으로** · **배속**(1 → 1.25 → 1.5 → 1.75 → 2 → 0.75배) · **볼륨**(끄기/켜기 + 슬라이더). 볼륨·창 위치·크기는 기기별로 기억합니다.
- 아이폰·아이패드는 기기 정책상 화면의 볼륨 슬라이더가 듣지 않을 수 있습니다(옆면 볼륨 버튼 사용).
- 창의 "YouTube" 버튼은 휴대폰에서는 YouTube 앱으로, 컴퓨터에서는 새 탭으로 엽니다. 퍼가기 재생은 브라우저가 제3자 쿠키를 막으면 프리미엄 광고 제거가 적용되지 않을 수 있는데, 그럴 때 이 버튼을 쓰면 됩니다.

## 사용 방법

`Sermons` 탭의 **status**:

| status | 뜻 | 할 일 |
|---|---|---|
| `pending` | 대기 | 다음 실행 때 정리 |
| `done` | 완료 (4모드 모두) | 웹앱에 표시 |
| `error` | 일부 또는 전체 실패 | `note` 확인. 성공한 모드는 저장되어 있고 다음 시도 때 빠진 모드만 다시 만듭니다 |
| `no_transcript` | 자막 없음 | `transcript_manual` 에 붙여넣고 `redo` |
| `redo` | 처음부터 다시 | 프롬프트를 고친 뒤에도 사용 |
| `skip` / `listed` | 제외 / 선택 대기 | 관리 화면에서 골라 정리 |

**예전(v8까지) 형식으로 정리된 설교**는 새 4모드 형식이 아니라서 화면에 나오지 않습니다. 관리 화면 "영상 선택해서 정리하기"에서 골라 다시 정리(`redo`)하세요.

## 알아 두실 점

- **자막 수집이 막힐 수 있습니다** (GitHub 서버 IP). `transcript_manual` 에 직접 붙여넣거나, 내 컴퓨터에서 `.env.example` 을 `.env` 로 채운 뒤 `npm install && node --env-file=.env scripts/sync.mjs`.

- **AI 정리의 한계**: 자막 오인식·요약 누락이 있을 수 있어 설교별 안내문(caveats)이 데이터에 들어갑니다.
- 한 번에 한 실행만 돌도록 되어 있어, 동시에 여러 번 누르면 순서대로 기다립니다.

## 말씀 게임

앱의 **첫 화면**이 말씀 게임 메인입니다(메뉴 맨 앞 **말씀 게임**, 구글 로그인 필요). 설교 목록은 메뉴의 **토론토영락교회 설교**에 있습니다. 가족(로그인한 사람)마다 기록이 따로 저장됩니다 (Google Sheet 의 `Game` 탭, 처음 쓸 때 자동 생성).

- **말씀 퀘스트**: 성경공부 모드의 퀴즈를 게임으로 풉니다. 객관식(보기 고르기)과 빈칸(키워드 직접 입력, 띄어쓰기·문장부호 무시). 주관식은 채점하지 않습니다.
  - 맞힌 문제만 점수: 객관식 4 XP · 2 달란트, 빈칸 6 XP · 3 달란트, 만점 보너스 20 XP · 15 달란트. 틀리면 0점.
  - 설교마다 처음 한 번만 점수, 하루에 점수 퀘스트는 2개까지(그 이상·다시 풀기는 연습). 채점은 서버가 다시 합니다.
- **도장**: 퀘스트를 절반 이상 맞히거나 묵상 퀘스트를 하면 그날 도장(+20 XP · 10 달란트). 연속 3일 ×1.2 · 7일 ×1.5 · 14일 ×1.7 · 30일 ×2 배 달란트, 7일마다 +50. 오래 쉬었다 오면 환영 보너스.
- **묵상 퀘스트**: QT 묵상 화면에서 묵상 질문에 내 답(모두 합쳐 30자 이상)을 적고 [묵상 퀘스트 완료하기] → +10 XP (설교마다 한 번).
- **안식 쿠폰**(상점 120 달란트, 최대 2장): 하루 쉬어도 연속 기록이 이어집니다.
- **여정**(하나 골라 진행, 경험치만큼 나아감, 끝나면 칭호 + 특별 아이템, 다른 여정으로 이어 가기): 천로역정 순례길(12곳) · 하나님의 전신갑주(6장비 × 청동/은/금) · 시냇가에 심은 나무(성장 4단계 + 성령의 열매 9개).
- **옷장 · 상점**: 귀여운 순례자 캐릭터(직접 그린 SVG). 머리·옷·모자·동물 친구·배경은 달란트로, 갑옷·면류관 등은 여정에서 얻습니다.
- **가족 순위**: 이번 주 경험치 순(매주 월요일 새로 시작), 레벨 칭호 · 업적 11개.
- 규칙·가격은 `docs/game-data.js` 에서 바꾸고 `node scripts/game-conf.mjs` 를 실행하면 `apps-script/Code.gs` 의 같은 값이 갱신됩니다(그다음 Apps Script 재배포).

## 퀴즈 · 묵상 질문 (AI 정리 규칙)

- 성경공부 퀴즈: **객관식 15문제**(쉬움 3 · 중간 7 · 어려움 5, 같은 설교·본문에서 가져온 그럴듯한 오답, 정답이 눈에 띄지 않게), **빈칸 5문제**(정답은 키워드 한 단어 + 같은 뜻의 다른 표기), **주관식 5문제**(채점 없음, 참고 답안).
- QT 묵상 질문과 소그룹 나눔 질문마다 **생각의 길잡이 + 예시 답안**이 붙습니다(평가용 아님, [길잡이 · 예시 답안 보기]로 펼침). 핸드아웃 PDF 에도 "정답·길잡이·예시 답안 포함"을 켜면 들어갑니다.
- 새 규칙은 앞으로 정리되는 설교부터 적용됩니다. 이미 정리된 설교는 관리 → 영상 관리에서 "다시 정리"를 누르면 새 형식으로 바뀝니다.

## "사이트 반영을 시작하지 못했습니다 … Unexpected inputs: export_only" 가 뜰 때

GitHub 에 올라간 `.github/workflows/sync.yml` 이 옛 버전이라는 뜻입니다. 이 폴더는 이름이 점(`.`)으로 시작해서 Mac 에서는 숨김 폴더라, `docs` 만 올리면 같이 올라가지 않습니다.
GitHub 저장소 화면에서 `.github/workflows/sync.yml` 을 열고 연필(Edit) 버튼 → 내용을 모두 지우고 새 `sync.yml` 내용을 붙여 넣은 뒤 Commit 하면 됩니다.
(Apps Script 를 이번 버전으로 다시 배포해 두면, 옛 sync.yml 이어도 일반 방식으로 반영은 시작합니다. 다만 새 sync.yml 이 더 빠르고 정확합니다.)

## 핸드아웃 PDF 만들기 · 내려받기

설교 화면의 **핸드아웃 PDF** 버튼 → 옵션을 고르고 **미리보기 새로고침** → **PDF 다운로드**.

- **옵션**: 보기 방식 · 용지 · 성경 본문 · 찬양 · 쓰는 줄 · 정답·모범 답안. 옵션을 바꾸면 미리보기가 흐려지고 다운로드가 잠기며, "미리보기 새로고침"을 눌러야 새 옵션으로 다시 만들어집니다 (미리보기와 내려받는 파일이 늘 같습니다).
- **용지**: 종이용 `Letter` · `A4`, 화면용 `디지털 · 태블릿`(7.5×10in, 3:4) · `디지털 · 휴대폰`(4×7.2in, 글자 크기·간격을 휴대폰에 맞춰 줄임). 파일 이름 끝에 용지가 붙습니다.
- **아이폰·아이패드**: 예전에는 "인쇄 → PDF로 저장"에만 의존했는데, iOS 인쇄 창에는 "PDF로 저장"이 없어서 안 됐습니다. 이제는 쪽마다 그림을 찍어 **PDF 파일을 직접 만들고**(`vendor/html2canvas.min.js`), 아이폰·아이패드에서는 "PDF 다운로드"를 누르면 공유 창이 떠서 "파일에 저장"(또는 GoodNotes·Notability 같은 필기 앱)으로 보낼 수 있습니다. 공유 창이 안 되는 기기는 일반 다운로드, 그래도 안 되면 "새 창에서 열기"를 쓰세요.
- 이 방식의 PDF 는 쪽이 그림이라 **글자 선택·검색은 되지 않습니다**. 글자가 살아 있는 PDF 가 필요하면 컴퓨터에서 **인쇄** 버튼(PC·Mac 에서만 보임) → "PDF로 저장"을 쓰세요.
- **쪽 나누기**: 문단 · 성경 절 · 목록 항목은 쪽 중간에서 끊지 않고 통째로 다음 쪽으로 넘깁니다. 한 쪽의 절반이 넘을 만큼 아주 긴 문단만 어쩔 수 없이 나누고, 그때도 앞뒤 3줄은 남깁니다. 본문은 왼쪽 정렬입니다.

## 핸드아웃(PDF) 꾸밈

- 제목은 영상 제목(`[날짜] 제목 (본문) - 설교자`)에서 날짜·본문·설교자를 뗀 깔끔한 제목으로 나오고, PDF 기본 파일 이름도 `말씀결_2026.10.04_제목_모드` 형태입니다.
- 맨 위에 말씀결 로고, 맨 끝에 만든 사람 표시가 들어갑니다. 문구는 `docs/config.js` 의 `CREDIT` 에서 바꾸거나 지울 수 있습니다.

## 이름·제목 통일

- **설교자**: `전대혁` · `전대혁 담임목사` · `토론토영락교회 전대혁` 등 어떤 형식이든 `전대혁 목사` 로 통일합니다 (전도사·강도사·장로·선교사·교수는 그 직함 그대로).
- **제목**: `주일예배 - 설교제목` 형식. 제목이 없는 영상(새벽기도회 등)은 `새벽기도 - 열왕기상 4, 5장` 처럼 성경 본문을 씁니다. 사용자 영상은 구분 이름을 붙이지 않습니다.
- 이미 정리해 둔 설교도 화면에서 같은 규칙으로 바로 바뀝니다 (다시 정리할 필요 없음).

## 제목·설교자·성경 본문·날짜 직접 고치기

설교 화면 맨 아래의 **"제목·설교자·본문·날짜 고치기 (관리자)"** 를 펼쳐 고칩니다.

- 관리 비밀번호로 저장합니다 (탭을 닫기 전까지 한 번만 입력). 바꾼 칸만 저장되고, 구분 이름("주일예배 - ")은 자동으로 붙습니다.
- 값은 Sermons 탭의 `title_override` · `preacher_override` · `scripture_override` · `date_override`(YYYY-MM-DD) 칸에 기록됩니다. 영상 제목이나 AI 결과는 그대로이고, **AI로 다시 정리해도 고친 값이 유지**됩니다. 두 칸은 시트에서 직접 고쳐도 됩니다.
- 칸을 비우고 저장하면 수정값이 지워지고 자동으로 정한 값으로 돌아갑니다.
- 저장하면 앱이 자동으로 "사이트에 반영"(`export_only`)을 요청합니다. 1~2분 뒤 모든 화면에 반영되며, 그 전에도 고친 기기에서는 바뀐 값이 먼저 보입니다.
- 성경 본문을 고치면 동기화가 새 본문의 성경 본문(4역본)과 낭독 영상을 다시 가져옵니다 (2~4분). 그 전에는 틀린 본문이 보이지 않도록 성경 본문 칸이 비어 있습니다. 표기 예: `요한복음 3:16-21` · `열왕기상 4, 5장` · `시편 23편`.
- 설교자 칸에는 이름만 써도 "OOO 목사"로 통일됩니다.
- Apps Script 코드(`apps-script/Code.gs`)를 새 것으로 바꾸고 **새 버전으로 배포**해야 저장이 됩니다.

## 사용자 영상 (정리된 영상 · 영상 추가)

- **사용자 영상** 메뉴는 두 칸으로 나뉩니다: **정리된 영상**(맨 위, 기본 화면)과 **영상 추가**(유튜브 링크 입력 + 내가 올린 영상의 진행 상황).
- 영상 추가에는 유튜브 주소만 넣으면 됩니다. **설교 제목 · 설교자 · 성경 본문 · 날짜는 영상 제목을 보고 자동으로** 채웁니다.
  - 읽는 형식 예: `진리를 분별하는 삶 | 전대혁 목사 | 요한복음 3:16-21` · `[주일설교] 믿음의 길 (창세기 12:1-9) - 홍길동 담임목사` · `2026.10.04 주일예배 열왕기상 4, 5장 윤정환 목사`
  - 제목에서 못 읽은 것은 AI가 설교 내용을 보고 채웁니다. 날짜는 제목의 날짜 → 유튜브 게시일 순서입니다.
  - 자동으로 읽은 값이 틀리면 설교 화면 맨 아래 "고치기"(관리자)로 고칠 수 있고, 미리 알고 있으면 "직접 입력 (선택)"에 적으면 그 값이 우선합니다.

## 형광펜 · 밑줄 · 메모 (나만 보기)

- 구글 로그인을 하면 설교 화면의 글(설교 정리 · 성경 본문 · 묵상 · 질문 등)을 끌거나 길게 눌러 고를 때 작은 도구 막대가 뜹니다.
  - 형광펜: 연한 노랑 · 연두 · 분홍 · 하늘 · 주황 · 보라 / 밑줄: 빨강 · 파랑 · 초록 · 보라 · 주황 / ✎ 메모 남기기
  - 칠한 곳을 누르면 색 바꾸기 · 메모 보기·고치기 · 지우기를 할 수 있습니다. 메모가 있는 곳에는 ✎ 표시가 붙습니다.
  - 모드 탭 오른쪽 **🖍 내 표시** 를 누르면 이 설교에 남긴 표시와 메모를 모아 보고, 눌러서 그 자리로 갈 수 있습니다.
- 저장은 Notes 탭의 `marks_json` 칸(본인 줄)에 자동으로 됩니다. 다른 가족에게는 보이지 않습니다.
- 표시는 문단 글자를 기준으로 붙습니다. 나중에 AI로 다시 정리해 글이 바뀐 문단의 표시는 화면에서는 사라지고 "내 표시" 목록에만 남습니다.
- 설교 한 편에 대략 200개 정도까지 남길 수 있습니다 (시트 칸 하나의 글자 수 한도).
- Apps Script 코드(`Code.gs`)를 새 것으로 바꾸고 새 버전으로 배포해야 저장됩니다.
